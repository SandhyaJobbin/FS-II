      - Start with `'use client';` on line 1.

      - Body: a single `useEffect(() => { ... }, [])` that:
        - Guards on `process.env.NODE_ENV === 'development'` — if false, return immediately.

      - No JSX render — return `null`.

Because AxeDevReporter is dev-gated and dynamic-imports axe-core, production bundles will not ship axe-core code.
