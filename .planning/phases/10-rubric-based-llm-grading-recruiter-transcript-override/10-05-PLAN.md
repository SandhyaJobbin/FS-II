## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin browser -> POST /overrideVerdict | Token in POST body (body-borne, NEVER query string); questionId + newVerdict cross this boundary |
| Admin browser -> GET /getAttemptTranscript | Token in query string (per project GET convention); returns rationale text potentially containing candidate-echoed content |
| Candidate browser -> ReportScreen render | Consumes `ungradedCount` integer only; MUST NOT consume rationale, criteriaMet, or transcript objects (A6) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-05a | Information Disclosure | Rationale/transcript rendered in candidate ReportScreen | high | mitigate | Task 3's automated verify greps confirm ReportScreen does NOT reference `report.rationale`, `transcript.rationale`, or `criteriaMet`. TranscriptPanel is a SIBLING of `<ReportScreen>` in the admin modal, not a child. |
| T-10-05b | Tampering | Admin token in query string of a mutation | high | mitigate | Task 2 uses POST with body-borne token for overrideVerdict, matching handleResetAttempt convention (admin/page.tsx:116-151). Query-string token would allow token leakage via browser history / referer headers. |
| T-10-05c | Spoofing | Cross-site request forgery on override endpoint | medium | accept | The admin panel is not publicly linked and requires the shared admin token — same trust model as adminResetAttempt. Adding CSRF tokens is a separate hardening phase; existing origin-of-request assumptions are unchanged by this plan. |
| T-10-05d | Denial of Service | Rapid-fire override clicks | low | mitigate | Task 2's `overriding` state disables the buttons for the currently-flipping questionId while awaiting the backend response. Backend LockService (plan 10-03) is the ultimate serialization guarantee. |
| T-10-05e | Repudiation | Candidate later disputes "I was told no human graded me" | medium | mitigate | Task 4's ThankYouScreen copy update is the disclosure that closes this gap — candidates are informed AT SUBMIT TIME that open-text answers may be reviewed by a recruiter. GRADE-10 requirement. |
| T-10-05-SC | Tampering | npm/pip/cargo installs | n/a | n/a | Plan installs zero packages — Package Legitimacy Gate not applicable. |
