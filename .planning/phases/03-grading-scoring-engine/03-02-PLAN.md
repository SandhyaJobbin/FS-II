# Phase 3, Plan 02 — Frontend Types, ReportScreen & Test Suite

## Goal

Align TypeScript types with the hardened backend contract, upgrade `ReportScreen.tsx` with rich Phase 3 display, and build the grading test suite.

## Changes

### assessment-app/src/types/index.ts

- Added `tables?: Record<string, string[][]> | null` to `Question`
- Added `startTime?` / `endTime?` to `Report` (optional — available on re-fetch)
- Added JSDoc on `Report`, `recommendationTier`, `narrativeInsight` fields

### assessment-app/src/components/ReportScreen.tsx

- **Trait progress bars** with 3-band colour (emerald/amber/red) and Framer Motion width animation
- **Dedicated narrative insight card** with left-border accent and blockquote treatment
- **Advisory recommendation section** with tier badge and disclaimer text
- **Framer Motion stagger** — each card fades up with 80ms inter-delay
- **Removed `(report as any).recommendation` cast** — uses `report.recommendationTier` directly

### tests/grading/grading-engine.ts  [NEW]

Pure TS extraction of Code.gs grading logic (no SpreadsheetApp). Exports:
- `gradeAttempt(questions, answers) → GradeResult`
- `computeTier(overall, critical, research) → Tier`
- `containsAnswerKey(obj) → boolean`

### tests/grading/test_grading.ts  [NEW]

29-test Vitest suite covering:
- **GRADE-01** (4 tests): determinism, empty answers, all-wrong, all-correct
- **GRADE-02** (7 tests): per-bank rollup, partial correctness, mcq_multi exact-match, case-insensitive, open_text
- **GRADE-03** (6 tests): narrative routing branches, no-complex proxy, level/section NOT used as proxy
- **GRADE-04** (5 tests): all tier boundaries, Strong Fit 3-condition gate, gradeAttempt produces tier
- **GRADE-05** (7 tests): containsAnswerKey detection, clean report passes, gradeAttempt result passes, client strip passes
