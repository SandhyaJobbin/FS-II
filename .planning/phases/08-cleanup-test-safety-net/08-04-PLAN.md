2. **Tier thresholds**: Extract tier boundary constants (80, 75, 75, 60) from both files. Verify match. Code.gs has these in `handleSubmitAnswers` (around line 550+); mirror has them in `computeTier` (line 179).
3. **Bank mapping**: Verify both map `attention → research`, `critical → critical`, default → `english`.
4. **Response type handling**: Verify both files handle all 4 response_type values: `mcq_single`, `mcq_multi`, `open_text`, `hybrid`. Fail if one adds a new type the other doesn't.
5. **ADMIN_TOKEN constant**: Verify mirror in `tests/admin/admin-auth.ts` matches Code.gs line 48 value.

Script reads both files as text, uses regex extraction. Exit code 0 = pass, 1 = divergence found. Print clear error messages showing which check failed and what values differ. Add `"sync-check": "npx tsx scripts/sync-check.ts"` to package.json scripts.
